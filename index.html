02 / System concept

Built for a difficult place to measure.

Cold rolling lines combine reflective steel, mist, vibration, and demanding strip speeds. This browser simulation explores a proposed non-contact sensing architecture and feedback loop for identifying carryover before it travels downstream.

Change simulated operating conditions, inspect the conceptual sensor bridge, and review the proposal. Telemetry is modeled locally; no mill sensors or control systems are connected.
